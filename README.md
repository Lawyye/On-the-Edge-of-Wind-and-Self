# On the Edge of Wind and Self

В этом репозитории **два независимых проекта**. Они лежат рядом, но друг от друга
не зависят:

| Проект | Где лежит | Что это | Где работает |
|---|---|---|---|
| 🌐 **Сайт «Орлеу Маңғыстау»** | папка [`site/`](site/) | Сайт с админкой для куратора: мероприятия, приём материалов от преподавателей | Vercel, проект `orleu-site` → https://orleu-site.vercel.app · база Supabase `supabase-lime-lens` |
| 🧠 **Psychology Bot** | корень репозитория (`bot.py`, `database.py`, `config.py`) | Telegram-бот анонимной психологической поддержки | AlwaysData (запускается вручную, `python bot.py`) |

Есть ещё ветка `claude/flutter-psychology-app-review-o5iptx` с черновиком мобильного
приложения на Flutter для того же психологического проекта. В `main` её пока не влили.

Всё про сайт: [`site/README.md`](site/README.md). Инструкция для куратора:
[`site/ИНСТРУКЦИЯ.md`](site/ИНСТРУКЦИЯ.md).

## 🧠 Psychology Bot: анонимная психологическая поддержка

Telegram-бот, через который люди анонимно просят о помощи и помогают друг другу.

**Что умеет:**
- 🆘 принять анонимную заявку о проблеме
- 💪 показать открытые заявки тем, кто хочет помочь
- 📝 передать ответ на заявку
- 💬 по желанию обменяться контактами после разговора

### Установка на AlwaysData

1. Создать бесплатный аккаунт на https://www.alwaysdata.com/ и выбрать Python 3.10+.
2. Загрузить проект:
   ```bash
   git clone https://github.com/Lawyye/On-the-Edge-of-Wind-and-Self
   cd On-the-Edge-of-Wind-and-Self
   ```
3. В разделе «Environment → Python packages» установить `python-telegram-bot`,
   `psycopg2-binary` и `python-dotenv`.
4. Создать на AlwaysData базу PostgreSQL, затем выполнить `cp .env.example .env` и заполнить:
   ```
   TELEGRAM_TOKEN=токен_бота
   DATABASE_URL=postgresql://пользователь:пароль@хост/база
   ```
5. Запустить: `python bot.py`.

**Где взять токен:** написать @BotFather в Telegram, отправить `/newbot`, следовать
подсказкам и вставить полученный токен в `.env`.

### Как это работает

- **Кому нужна помощь:** `/start` → «🆘 Мне нужна помощь» → заполнить форму
  (название, описание, категория) → получить ID заявки и ждать ответов.
- **Кто помогает:** `/start` → «💪 Помочь другому» → выбрать заявку из списка →
  написать ответ. Если ответ понравится автору, вы получите его контакт.
