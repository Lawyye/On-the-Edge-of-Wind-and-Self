# Edgewind — «On the Edge»

Flutter-приложение: анонимное место, где можно оставить свою историю, ответить
другому человеку или просто почитать. Android и десктоп.

Пакет: `com.ontheedge.edgewind`.

---

## Откуда взялся этот код

Исходники были потеряны вместе с компьютером, на котором писались. Уцелел
только `app-debug.apk`.

Debug-сборки Flutter укладывают в `assets/flutter_assets/kernel_blob.bin`
полный текст Dart-исходников — он нужен виртуальной машине, чтобы печатать
стектрейсы с номерами строк. Все 12 файлов извлечены оттуда целиком: у каждого
сходится баланс скобок, каждый заканчивается закрывающей `}`.

Оригинальные пути были `C:/Users/123/StudioProjects/edgewind/lib/...`, версии
зависимостей взяты из путей pub-кеша в той же сборке, поэтому `pubspec.yaml`
описывает ровно то окружение, на котором приложение собиралось (Dart SDK 3.12.2).

Из релизной (`--release`) сборки так восстановить исходник **нельзя** — там
AOT-машинный код без текста. То, что сборка оказалась отладочной, и спасло проект.

## Как собрать заново

Платформенные папки (`android/`, `windows/`, ...) в APK не лежат — их
восстанавливает сам Flutter:

```bash
cd app
flutter create --org com.ontheedge --project-name edgewind .
flutter pub get
flutter run
```

`flutter create` в существующей папке дописывает только недостающее и не трогает
`lib/`, `pubspec.yaml` и `assets/`.

## Как собрать APK, который открывается быстро

Тот APK, что был на руках, — **отладочный**, и именно поэтому он открывался
10–15 секунд:

| | debug (что было) | release (как надо) |
|---|---|---|
| Размер | 185 МБ | ~10–15 МБ на ABI |
| Dart-код | `kernel_blob.bin` 44 МБ, JIT-компиляция при каждом запуске | AOT, скомпилирован заранее |
| Vulkan validation layers | `libVkLayer_khronos_validation.so`, 15 МБ | нет |
| ABI в пакете | все три сразу (108 МБ движка) | по одной |
| Запуск | 10–15 с | обычно меньше 2 с |

```bash
flutter build apk --release --split-per-abi
```

Готовые файлы появятся в `build/app/outputs/flutter-apk/`. Для большинства
телефонов нужен `app-arm64-v8a-release.apk`.

Отладочную сборку раздавать не стоит: она медленная, весит в десять с лишним раз
больше и, как видно выше, отдаёт весь исходный код любому, кто её распакует.

## Что внутри

```
lib/
  main.dart                     точка входа
  app.dart                      MaterialApp, тема Material 3
  domain/
    models.dart                 Story, StoryResponse, TechReport (+ JSON)
    categories.dart             список тем
  data/
    edgewind_store.dart         ChangeNotifier поверх SharedPreferences
  screens/
    home_screen.dart            лента, вкладки
    compose_sheet.dart          новая запись
    story_sheet.dart            история и отклики
    notifications_page.dart     уведомления
    profile_pages.dart          профиль, приватность, аватар
  widgets/story_card.dart       карточка истории
  ui/time_text.dart             «5 мин назад»
```

## Важное про данные

Сети в приложении нет: ни `http`, ни `dio` — только `shared_preferences`.
Истории, отклики, сохранённое и аватар лежат **только на устройстве**, ключами
`edgewind.*`. Пользователи друг друга не видят, и это честно написано в самом
интерфейсе («Пока всё на устройстве»).

Telegram-бот в корне репозитория — отдельная программа, с приложением он никак
не связан.
