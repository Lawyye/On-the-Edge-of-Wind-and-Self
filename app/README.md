# Edgewind — «On the Edge»

Flutter-приложение: место, где можно оставить свою историю без настоящего
имени и получить отклик от других. Собирается под Android.

Пакет: `com.ontheedge.edgewind`. Готовый APK — в релизе
[`apk`](https://github.com/Lawyye/On-the-Edge-of-Wind-and-Self/releases/tag/apk),
его собирает `.github/workflows/build-apk.yml` при каждом изменении `app/`.

---

## Откуда взялся код

Исходники были потеряны вместе с компьютером, на котором писались. Уцелел
только `app-debug.apk`: Flutter в отладочных сборках кладёт в
`kernel_blob.bin` полный текст Dart-исходников, оттуда всё и восстановлено.
С тех пор приложение переписано почти целиком.

## Как собрать и проверить

Нужен Flutter **3.50.1** — та же версия закреплена в сборке на GitHub.

```bash
cd app
flutter create --org com.ontheedge --project-name edgewind --platforms android .
flutter pub get
dart run flutter_launcher_icons        # иконка
flutter test --exclude-tags golden     # тесты: кнопки, вёрстка на маленьком экране
flutter run
```

Снимки всех экранов на готовых данных, без сети и телефона:

```bash
flutter test --update-goldens test/screens_golden_test.dart
# картинки — в test/goldens/ (в репозиторий не идут)
```

Релиз: `flutter build apk --release --split-per-abi`, для почти всех телефонов
нужен `app-arm64-v8a-release.apk`. Отладочную сборку раздавать нельзя: она
в десять раз тяжелее, запускается 10–15 секунд и отдаёт весь исходный код.

## Подпись

Android ставит обновление поверх приложения, только если обе версии подписаны
**одним** ключом. Ключ лежит в секрете репозитория `ANDROID_KEYSTORE_B64`
(base64 от keystore с паролем `android` и псевдонимом `androiddebugkey`) и
при сборке кладётся в `~/.android/debug.keystore`, откуда его берёт подпись
по умолчанию. Без секрета сборка проходит, но каждая версия подписана новым
случайным ключом — и обновление требует удалить приложение, а вместе с ним и
анонимный аккаунт. Отпечаток подписи печатается в шаге «Отпечаток подписи».

## Сервер

Supabase, проект `wwwxthxyfglcgpuscafz`. Адрес и публикуемый ключ — в
`lib/data/supabase_config.dart`; ключ не секрет, доступ решают правила базы.
Схема, защита и проверка атаками — в [`../supabase/README.md`](../supabase/README.md).

## Оформление

Три картинки — девушка ночью у старого монитора, провода на сиреневом закате,
ромашки на чёрном — и всё остальное строится вокруг них. У каждого экрана своя
шапка-кадр с развёрткой и зерном; при прокрутке она сворачивается в узкую
тёмную полосу. Заголовки экранов — тонкий моноширинный с расходящимися
цветовыми каналами, по краю кадра — вертикальная японская подпись.

Машина говорит моноширинным JetBrains Mono: метки, время, счётчики, кнопки.
Человек — книжной Literata: заголовки и тексты историй, отклики. Тёплый цвет
один и редкий — им горит только человеческое: «я рядом», свои отклики,
полученные значки.

У каждой истории в ленте свой знак-сигнал: симметричный пиксельный узор из её
id в цвете темы. Достижения — значки с пиксельными иконками, как в библиотеке
игр; выдаются за отклик другим и за возвращение, ни одно — за количество
собственных тяжёлых историй.

## Безопасность человека

Если в тексте новой записи звучит угроза жизни, под полем появляется карточка
с номером 150 и кнопкой звонка; публикации это не мешает. Читателям такой
истории приложение подсказывает отвечать бережно. Экран «Если очень плохо»
есть в ленте и в профиле: 150, 111, 112 и российский 8-800-2000-122.
