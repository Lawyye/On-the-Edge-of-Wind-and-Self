# Дизайн приложения «On the Edge»

Исходники холста Claude Design. Каждый `.dc.html` — отдельный экран,
`canvas.json` расставляет их на холсте.

```
Welcome    первый вход
Main       лента
Story      история и отклики
Compose    новая запись
Responses  отклики
Profile    профиль
System     визуальная система: цвета, кегли, радиусы для переноса в Flutter
```

Направление — «тихое поле». Палитра взята из кода приложения
(`lib/widgets/story_card.dart`, `lib/app.dart`) и развита, а не заменена.
Гарнитуры: **Literata** для авторского текста, **Golos Text** для интерфейса —
обе нарисованы с кириллицей в основе.

Правки вносятся в `.dc.html`, затем холст пересобирается и публикуется заново.
Собранный файл в репозиторий не коммитится.
