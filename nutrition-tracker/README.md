# Рацион — персональный трекер питания для Android

Личный дневник питания: калории, БЖУ, витамины и минералы, рецепты, голосовой
ввод, вес и измерения тела. Без аккаунтов, серверов, рекламы и платных API.
Все данные хранятся на телефоне.

Главное правило проекта: **приложение не придумывает пищевую ценность**. Если
источник не сообщает содержание вещества, хранится и показывается «нет данных»,
а не ноль. Суммы, где данные есть не для всех продуктов, помечаются как нижняя
граница (`≥`), и недостаток вещества по ним не утверждается.

## Установка

Готовый APK выкладывается в релиз
[`nutrition-apk`](https://github.com/Lawyye/On-the-Edge-of-Wind-and-Self/releases/tag/nutrition-apk)
после каждой успешной сборки в CI. Откройте ссылку на телефоне, скачайте
`racion-release.apk` и установите (Android попросит разрешить установку из этого
источника). Обновления ставятся поверх, данные сохраняются: release подписан
постоянным ключом.

Требования: Android 8.0 (API 26) и новее.

## Структура

```
nutrition-tracker/
├── core/     чистый Kotlin: нутриенты, расчёты, нормы, разбор голоса, формат бэкапа
├── remote/   клиенты USDA FoodData Central и Open Food Facts (Retrofit + OkHttp)
├── app/      Android: Room, DataStore, WorkManager, Jetpack Compose
└── ci/       скрипт проверки на эмуляторе
```

| Слой | Что внутри |
|---|---|
| `core` | `Nutrients` (неизвестное ≠ 0), пересчёт на массу, суммы с признаком полноты, рецепты по весу готового блюда, BMR (Миффлин — Сан Жеор), TDEE, дефицит с защитой от слишком низкой калорийности, тренд веса, адаптивный расход, нормы NASEM DRI, проверка калорий по БЖУ, стеммер и словарь RU→EN, разбор голосовых фраз, резервная копия JSON и CSV |
| `remote` | сопоставление нутриентов USDA по номерам с порядком предпочтения, перевод единиц только точными коэффициентами, справочные порции, разбор Open Food Facts (г/мл, кДж→ккал) |
| `app` | 12 таблиц Room со снимками пищевой ценности в дневнике, репозитории, синхронизация кэша, экраны на Compose |

## Сборка

Нужны JDK 21 и Android SDK (compileSdk 37.2). Gradle скачивается обёрткой.

```bash
cd nutrition-tracker
./gradlew :app:assembleDebug        # отладочная сборка
./gradlew :app:assembleRelease      # release (R8)
./gradlew :core:test :remote:test :app:testDebugUnitTest   # тесты
```

Без Android SDK и Google Maven (например, в изолированной среде) можно собрать и
проверить расчёты и сетевые клиенты:

```bash
NT_JVM_ONLY=1 ./gradlew :core:test :remote:test
```

### Подпись release

Ключ берётся из переменных окружения `NT_KEYSTORE_FILE`, `NT_KEYSTORE_PASSWORD`,
`NT_KEY_ALIAS`, `NT_KEY_PASSWORD` или из файла `keystore.properties` в корне
проекта:

```properties
storeFile=/путь/к/release.keystore
storePassword=...
keyAlias=...
keyPassword=...
```

Файл и ключ в репозиторий не попадают (`.gitignore`). Без ключа release
подписывается отладочным ключом, и такой APK не встанет поверх версии,
подписанной постоянным ключом. В CI ключ берётся из секрета
`ANDROID_KEYSTORE_B64`.

### Ключ USDA API

USDA FoodData Central работает с общим ключом `DEMO_KEY` (мало запросов в час).
Личный бесплатный ключ выдаётся на <https://api.data.gov/signup/> и вводится в
приложении: **Профиль → Настройки → Ключ USDA API**. Он хранится только на
телефоне и не попадает в резервную копию. В APK ключ не встраивается.

Для разработки можно положить ключ в `local.properties` — он попадёт только в
отладочную сборку:

```properties
usda.apiKey=ваш_ключ
```

Open Food Facts ключа не требует.

## CI

Workflow `.github/workflows/nutrition-android.yml`:

1. тесты `:core`, `:remote` и Robolectric-тесты базы данных;
2. сборка debug, release и инструментальных тестов, проверка подписи;
3. эмулятор (API 34): онбординг через интерфейс, переустановка поверх с
   проверкой сохранности данных, снимки экранов, запуск release и случайные
   нажатия (`monkey`) без падений;
4. публикация APK в релиз `nutrition-apk`.

## Данные и приватность

- База Room, схемы версий — в `app/schemas`. Разрушающие миграции не
  используются: при обновлении данные не удаляются.
- Записи дневника хранят снимок пищевой ценности на момент добавления:
  обновление или удаление продукта не меняет историю.
- `android:allowBackup="false"`: дневник не копируется в облако Google. Перенос
  на другой телефон — через резервную копию JSON (Профиль → Резервная копия).
- В интернет уходят только поисковые запросы и идентификаторы продуктов — к USDA
  и Open Food Facts. Журналирование HTTP отключено.
- Разрешения: интернет, состояние сети и микрофон (запрашивается при первом
  нажатии на кнопку голосового ввода).

## Источники

- USDA FoodData Central — <https://fdc.nal.usda.gov/> (CC0).
- Open Food Facts — <https://world.openfoodfacts.org/> (ODbL).
- NASEM Dietary Reference Intakes, сводные таблицы NIH ODS.
- Mifflin MD et al. A new predictive equation for resting energy expenditure in
  healthy individuals. Am J Clin Nutr. 1990.

Приложение не ставит диагнозов и не заменяет консультацию врача.
