# Сайт «Орлеу Маңғыстау» — копия + админка

Копия сайта `sites.google.com/view/orleumangistaukdi` со своей админкой, чтобы куратор
могла менять даты и тексты сама и принимать материалы от преподавателей.

- **Стек:** Next.js 15 (App Router) + TypeScript, Supabase (Postgres + Storage), Vercel.
- **Секреты в браузер не попадают.** Все записи идут через серверные маршруты
  с service-role ключом.
- **Пока Supabase не подключён** сайт читает `seed/content.json` и работает в режиме
  «только чтение» — то есть он открывается и выглядит правильно с первого деплоя.

## Запуск локально

```bash
cd site
npm install
cp .env.example .env.local   # заполнить
npm run dev
```

## Настройка (делается один раз)

### 1. Supabase

1. Завести бесплатный проект на [supabase.com](https://supabase.com).
2. Открыть **SQL Editor** → вставить целиком `supabase/schema.sql` → **Run**.
   Создадутся таблицы и два бакета: `materials` (приватный) и `images` (публичный).
3. **Project Settings → API** скопировать:
   - `Project URL` → `SUPABASE_URL`
   - `service_role` ключ → `SUPABASE_SERVICE_ROLE_KEY` (секрет, в браузер не отдаётся)

### 2. Переменные в Vercel

Если проект на Vercel подключён к Supabase через официальную интеграцию,
`SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` подставляются автоматически —
руками ничего вводить не нужно.

Остальное необязательно:

| Переменная | Когда нужна |
|---|---|
| `ADMIN_BOOTSTRAP_PASSWORD` | запасной вход, если пароль куратора забыт |
| `AUTH_SECRET`, `IP_HASH_SALT` | только чтобы зафиксировать или сменить их вручную |
| `CRON_SECRET` | Vercel подставляет сам |

Пароль куратора хранится хешем в таблице `settings` и меняется во вкладке
«Настройки». Ключ подписи сессий и соль для хеша IP приложение генерирует само
при первом запуске и кладёт туда же — см. `lib/secrets.ts`.

### 3. Root Directory

Проект живёт в подпапке. В Vercel **Settings → General → Root Directory** указать `site`.

## Что где

```
app/
  page.tsx              главная
  [...slug]/            кураторы и мероприятия по кириллическим адресам оригинала
  materials/            публичный архив опубликованных материалов
  submit/               форма для преподавателей, без регистрации
  admin/                вход + панель
  api/
    submissions/        приём заявки: honeypot, задержка, лимит, проверка файла
    file/[id]/          выдаёт временную ссылку, и только на опубликованное
    admin/              login, submissions, content, settings, password, upload-image
    cron/keepalive/     не даёт бесплатному Supabase уснуть
lib/                    supabase, auth, ratelimit, validate-file, content
seed/content.json       содержимое оригинала — запасной вариант и стартовые данные
supabase/schema.sql     таблицы, бакеты, RLS
```

## Защита от спама

Главный барьер — **премодерация**: документ виден на сайте только после кнопки
«Опубликовать». Дополнительно на сервере:

- скрытое поле-ловушка (honeypot);
- отсечка форм, отправленных быстрее 3 секунд;
- не больше 5 заявок в час с одного адреса;
- проверка файла по расширению, MIME **и сигнатуре первых байт** — переименованный
  `.exe` не пройдёт;
- максимум 20 МБ, разрешены pdf/doc/docx/ppt/pptx/xls/xlsx/jpg/png;
- выключатель «приём закрыт» в админке.

## Персональные данные

Статус пока неизвестен, поэтому по умолчанию осторожно:

- IP не хранится — только солёный хеш, нужный для лимита;
- файлы лежат в приватном бакете, ссылка временная и выдаётся только на опубликованное;
- публично видно имя, организацию и район — не почту и не телефон;
- в форме обязательная галочка согласия, время отметки пишется в `consent_at`.

## Про фотографии

Изображения оригинала перенесены в Supabase Storage (бакет `images`, префикс
`original/`) и больше нигде не хранятся. Старый Vercel-проект
`orleu-mangistau-kdi`, с которого они грузились раньше, остановлен и не нужен.

`lib/assets.ts` по-прежнему умеет разворачивать пути вида `/assets/source/...`
в адрес старого деплоя — это осталось как страховка на случай, если где-то
всплывёт непере­несённая ссылка. Разовый перенос лежит в
`app/api/admin/migrate-images` и запускается кнопкой во вкладке «Настройки»;
запускать его повторно безопасно.
